# AI / データサイエンス 転職ナビ

AI・データサイエンス人材の**想定年収と相性の良い転職先**を、出典つきデータで診断するWebアプリ（日本国内市場向け）。

**▶ デモ: https://pandas-mizugorou.github.io/ai-career-navigator/**

年齢・経験年数・役割・保有スキル・勤務地を入力すると、以下を提示します。

- **想定年収レンジ**（点ではなく幅で提示。計算内訳を全て開示）
- **相性の良い転職先タイプ**（企業タイプ別の市場レンジ・年収順）
- **年収を引き上げる打ち手**（スキル別の伸びしろ順）と**転職活動の打ち手**
- **この先の年収カーブ試算**

## 設計思想 — 「正確性を構造で担保する」

年収診断ツールは「盛った数字」を出しがちです。本ツールは逆に、**誇張をアーキテクチャレベルで抑制する**ことを最優先に設計しています。

### 1. すべての数値に出典と信頼区分（tier）を付与

画面に表示される実在値には出典バッジが付きます。信頼区分は5段階で、エージェント系メディアの数字には「高めに出る傾向」の注記を利用者に開示します。

| 区分 | 意味 |
|---|---|
| ◎ official | 政府・公的統計（厚労省 job tag 等） |
| ○ survey | 人材会社の年収調査レポート |
| □ posting | 実際の求人票の提示レンジ |
| △ agency | 転職メディアの集計・解説記事（高めバイアスを明示） |
| ⚙ tool | 本ツールの計算ロジック（実測値ではないことを明示） |

### 2. 公的統計をアンカーにした推定ロジック

年齢別の推定は厚労省「賃金構造基本統計」の実測値・国税庁「民間給与実態統計」をアンカーに置き、役割・スキルによる上振れは **cap/clamp（上限抑制）** で構造的に制限。「入力を盛れば青天井」になることを防ぎます。

### 3. データの鮮度を自己申告

データ層（`data.js`）は `last_updated` を持ち、**90日を超えると画面上に「要更新」警告**が自動表示されます。古いデータを新しい顔で見せません。

### 4. データ層の二層構造

- **年次同期層**（公的統計アンカー・補正係数・計算式）: 官公庁の年次統計の発表時のみ人間が更新。頻繁に触らないことで推定の一貫性を守る
- **月次更新層**（職種別平均・求人レンジ・需要スキル）: 市場の動きに合わせて更新

更新手順は [`UPDATE.md`](UPDATE.md) にランブックとして固定化しており、AIエージェント（Claude Code）に「データ更新して」と依頼するだけで再調査→差し替え→検証が回る運用です。

## 技術構成

- **Vanilla JS + HTML + CSS のみ**（ビルド・フレームワーク不要の単一ページ）
- ロジック（`index.html`）とデータ（`data.js`）の完全分離 — 数値の更新でロジックに触らない
- **PWA対応**（`manifest.json` + Service Worker。ホーム画面追加・オフライン閲覧）
- ホスティング: GitHub Pages（静的配信のみ・サーバー不要）

## 免責
